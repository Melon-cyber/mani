# Мани

Учёт расходов и доходов для Android. Без рекламы, без аккаунтов и без серверов: все операции хранятся только на телефоне.

## Возможности

- Быстрый ввод в пару нажатий: своя цифровая клавиатура, категория, заметка, сегодня/вчера/любой день.
- Месяц на одном экране: доходы, расходы, остаток, кольцевая диаграмма по категориям и список операций по дням. Нажми на категорию, чтобы увидеть только её.
- Бюджет на месяц и лимиты по категориям с предупреждением о превышении.
- Аналитика: траты за полгода, среднее в день, сравнение категорий с прошлым месяцем.
- Свои категории со значком и цветом; категория с операциями прячется, а не удаляется.
- Удалённую операцию можно вернуть одним нажатием.
- Выгрузка в CSV для Excel и Google Таблиц, копия в файл и восстановление.
- Валюта на выбор: ₽, ₸, Br, сум, ₴, $, €.

## Сборка

Нужны JDK 17+ и Android SDK 36. `./gradlew :app:assembleRelease`. Подпись настраивается файлом `keystore.properties` (не попадает в Git); без него используется стандартный отладочный ключ.
